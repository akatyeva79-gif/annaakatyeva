# Внешняя обработка «Удалить неключевые платформы»

**Платформа:** 1С:Предприятие 8.3.25 (управляемое приложение)  
**Архитектура:** Клиент–сервер  
**СУБД:** MS SQL Server  
**Версия ТЗ:** 1.0  
**Статус:** В разработке  

---

## 📌 Назначение

Внешняя обработка предназначена для управления и очистки константы **«ПлатформыРезерв»**, которая содержит указатели на элементы справочника **«Платформы»**.

Обработка удаляет из константы все ссылки на платформы с признаком *«Ключевая = Ложь»* и отображает результаты очистки в наглядном виде пользователю.

---

## 🎯 Основные возможности

- ✅ Автоматическая очистка константы от неключевых платформ
- ✅ Поддержка трёх форматов хранения данных (строка GUIDов, массив ссылок, таблица значений)
- ✅ Отображение оставшихся платформ в таблице (сортировка по убыванию ЧисловойКод)
- ✅ Кликабельные ссылки на элементы справочника
- ✅ Информационное сообщение об удалённых элементах (с сортировкой по возрастанию кода)
- ✅ Оптимизированное клиент-серверное взаимодействие

## ❓ FAQ

**Q: Что происходит, если константа пуста?**  
A: Обработка завершается без ошибок, таблица остаётся пустой, сообщение не выводится.

**Q: Какой формат сохраняется в константе после обработки?**  
A: Всегда массив ссылок в `ХранилищеЗначений`, независимо от исходного формата.

**Q: Можно ли откатить удаление?**  
A: Нет, удаление необратимо. Рекомендуется сохранять резервные копии перед использованием.

**Q: Как открыть платформу из таблицы?**  
A: Двойной щелчок по ячейке с названием платформы откроет её форму.
