# Функциональные и нефункциональные требования

## 1. Основные параметры

### 1.1 Справочник «Платформы»

| Реквизит | Тип | Размер | Особенности |
|----------|------|--------|----------|
| **Наименование** | Строка | 100 символов | Название платформы |
| **ЧисловойКод** | Число | 3 | Диапазон 100–999; контроль уникальности |
| **Ключевая** | Булево | — | Признак ключевой платформы |

### 1.2 Константа «ПлатформыРезерв»

Тип данных: **ХранилищеЗначений**

Может содержать три формата:

1. **Строка GUIDов** (разделенных `;`)
2. **Массив ссылок** (на элементы справочника)
3. **ТаблицаЗначений** (с колонкой "Платформа")

## 2. Основная функция

### 2.1 Команда «Удалить неключевые»

**Функция:**
- Удалять из константы все ссылки на платформы, у которых **Ключевая = Ложь**
- Показать на форме таблицу оставшихся ключевых платформ
- Вывести сообщение о удалённых элементах

### 2.2 Минимальные требования

- Обрабка данных на сервере
- Отображение результатов динамической таблицей (1 строка, N колонок)
- Кликабельные ссылки (на открытие формы элемента)
- Информационное сообщение

## 3. Клиент-серверное взаимодействие

- Во всех операциях с базой данных — **на сервере**
- Все запросы выполняются на MS SQL
- Отображение таблицы — на клиенте
